# 분수 익히기

피자·초콜릿·색종이 애니메이션으로 분수의 뜻부터 사칙연산까지 익히는 웹 학습지입니다.
`index.html`을 열면 바로 실행됩니다(설치 불필요, 오프라인 동작).

## 사용한 오픈소스
- [Fraction.js](https://github.com/rawify/Fraction.js) (MIT) — 분수 계산·채점
- [anime.js](https://github.com/juliangarnier/anime) (MIT) — 애니메이션
- [canvas-confetti](https://github.com/catdad/canvas-confetti) (ISC) — 축하 효과
- [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL) — 글꼴
- $P Point-Cloud Recognizer (New BSD) — 손글씨 숫자 인식 알고리즘
